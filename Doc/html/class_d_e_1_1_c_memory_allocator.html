Detailed Description

template<typename T>
class DE::CMemoryAllocator< T >

CMemoryAllocator template class.

Manages memory allocation. The goal of this class is to give an interface to allocate memory tables. In order to avoid dynamic memory allocation/desallocation, this interface allocate all the necessary memory of a defined type once, wich will be availibe dynamically. This is important to minimize memory errors and optimize the game during the real time rendering.
